# Third-party notices — `@cotuong/shared`

## Cờ thế (xiangqi puzzles) data — xiangqi-tools

`src/puzzles.ts` contains data derived from the file `fen/shiqingyaqu551.fen` of the
**xiangqi-tools** repository by Careone Kuiba: <https://github.com/kuiba1949/xiangqi-tools>

Used: the FEN positions, the Chinese names and the `*` marks of puzzles 1–200 of
适情雅趣_李浭551局新版 (适情雅趣 — "Thích tình nhã thú"). The Vietnamese (Hán Việt) names and review notes of puzzles 1–100 come from
a document supplied for this project; the `mateIn` / `solution` fields were computed for this project.
The same notice and license text are shipped inside the data module (`PUZZLE_SOURCE`, `PUZZLE_LICENSE_TEXT`)
and shown on the website's Cờ thế page (section "Nguồn").
